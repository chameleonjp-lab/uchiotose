# 浮島上の城

依頼: 浮島の上に、島のサイズより高さのある荘厳な城を設置する。

城の基部は島の上面と同じ高度800m、頂点は高度3200m。島からの高さは2400mで、島の最大横幅2000mを上回る。足元の半径810mは、島上面の16角形に収まる。

白い石造りの中央大塔、濃紺の尖塔屋根、4つの側塔と8つの城壁塔、金色の縁、アーチ窓、3段のテラスで構成する。360度から城の形が見えるよう、中央を最も高くして塔を周囲へ配置する。

## 今回の変更範囲

城は静的な景観モデル。飛行機や弾に対する城独自の当たり判定、城による視線の遮蔽は追加していない。既存の浮島の岩に対する判定を使う。飛行高度の上限、操縦、カメラ、敵や味方の数、得点、スポーン位置は変更していない。

同じ材質の部品を5つの描画用形状へまとめ、毎フレームの作り直しと外部画像の読み込みを避ける。WorldRendererの生成時に一度作成し、破棄時に形状・材質を解放する。

## 検査

`tests/castle-visual.test.ts`で、島幅より高いこと、足元が島上面に収まること、有限の座標・索引、描画回数と頂点データの上限、二重破棄を検査する。

`browser-tests/castle-scenery.spec.ts`で393×852と852×393のHome画面と、実際のWorldRendererを使った城の正面・近景・背面を撮影する。城の確認用カメラを使う画像と、通常のHome画面を区別し、画像取得時のソースSHA-256と描画資源数も保存する。画像の撮影では戦闘を進めない。

既存のUI-only検査と通常の単体検査を維持する。長時間の戦闘検査3件は従来どおり任意実行。実iPhoneのSafariや実際の携帯端末の描画速度は、模擬検査の成功では確認済みとしない。
